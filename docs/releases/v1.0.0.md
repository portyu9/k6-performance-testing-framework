# v1.0.0 — Production-grade k6 performance testing framework

## What this release establishes

- smoke, load, stress, and soak profiles with explicit workload semantics;
- centralized threshold/SLO policy;
- tagged business metrics;
- exact-host authorization for sustained traffic;
- deterministic repository-owned smoke execution;
- zero-sustained-traffic configuration validation;
- governed Docker runtime and security evidence;
- machine-readable summaries with target/run attribution;
- stable CI aggregate gates;
- discovery-focused examples and technical guides.

## Position

**Safe by default. Evidence by design.**

The framework treats sustained performance testing as an explicitly authorized experiment and treats every green state as something that should be explainable by attributable evidence.

## Release qualification

Publish this as the GitHub v1.0.0 release only from the reviewed main-branch commit after `ci-gate`, `extended-gate`, `security-gate`, and documentation contracts pass.
